# Junyoung's SemiLab

A minimal personal semiconductor study archive.

## Sections

- Profile
- Study Notes
- Paper Library

## Run locally

```bash
npm install
npm run dev
```

## Edit content

Study notes and paper entries are stored in:

`src/data/content.ts`

The current version intentionally keeps the site simple. Future additions can include Markdown-based notes, DOI/URL storage, PDF links, database-backed paper management, and AI/RAG search.
